# 内容排版与合规自检清单模板

> 面向「粘贴到第三方内容平台编辑器」的 HTML 图文生产流程。
> 颜色、账号名等品牌要素全部用占位符，复制后自行替换。

## 一、品牌要素占位符

| 要素 | 占位符 | 说明 |
|------|--------|------|
| 账号名 | `{{账号名}}` | |
| 品牌/机构名 | `{{品牌名}}` | |
| 主色 | `var(--brand-primary)` / `{{主色色值}}` | 标题、分割线、表头、按钮 |
| 次色 | `var(--brand-secondary)` / `{{次色色值}}` | 次级节点、对比项 |
| 背景灰 | `#F5F5F5`（可按品牌调整） | 引用块、隔行底纹 |
| 正文色 | `#3c3c3c`（可按品牌调整） | |
| 禁用色 | `{{禁用色，如红/橙}}` | 按账号调性设定，全文统一不使用 |

## 二、HTML 兼容性规范（平台编辑器防崩）

1. **扁平结构**：不依赖 `section`/`div` 多层嵌套，段落直接用 `<p>`，每个标签自带全套行内样式。
2. **禁用 h1-h6**：部分平台会覆盖标题标签默认样式；章节标题用带样式的 `<p>` 实现。
3. **引号规则**：正文叙述用全角引号；HTML 属性用半角引号。
4. **行内换行**用 `<br>`，不用 `<div>`（部分编辑器会把 div 渲染成大段空行）。
5. **图片**：预览页可用相对路径；正式发布必须替换为平台素材库 URL（SVG 多数平台不支持，先转 PNG，见 `scripts/svg_to_png.ps1`）。
6. **表格**：用 `border-collapse:collapse` + 单元格行内样式；不依赖 `<style>` 标签和 class。
7. **滚动容器**（`overflow-y:auto`）在不同 App 版本表现不一致，发布前必须在目标平台预览；失效时内容应能完整展开，不影响阅读。

## 三、内容结构自检

- [ ] 开场不是套路化场景（如「群里安静了」式开头），优先具体数字、反常识结论或真实问题。
- [ ] 核心论点有数据/事实支撑，事实库引用已回查原件。
- [ ] 关键句有加粗或色块强调，每屏至少一个视觉落点。
- [ ] 推广内容与正文存在逻辑衔接（用户问题 → 解决方案），不硬转。
- [ ] 结尾有一句话总结，可独立转发成立。

## 四、合规自检

- [ ] 推广区块字数占比 ≤ 30%（用 `scripts/ratio_check.py` 检查）。
- [ ] 文末包含广告/合作披露声明，例如：
  > 本文为「{{账号名}}」与{{品牌名}}联合推广内容，涉及产品、价格、服务等信息以{{品牌名}}官方渠道为准。
- [ ] 涉及政策、考试、录取等内容附免责声明，例如：
  > 本文政策信息整理自公开渠道，具体以主管部门当年官方发布为准。
- [ ] 效果类表述使用「个案，不构成承诺」式限定，不出现保证性承诺。
- [ ] 无未公开定价、内部人员名单、未发布计划、用户个人信息。
- [ ] 无绝对化用语与平台规则列明的违禁词。

## 五、发布前技术检查

- [ ] 预览页在浏览器打开正常（`scripts/html_inject.py` 注入后检查）。
- [ ] 图片均为平台支持的格式（PNG/JPG/GIF）且已上传素材库。
- [ ] 粘贴到平台后台后，在手机上预览：底色块、表格、分割线不跑位。
- [ ] 全文搜索占位符（`{{`）确认无遗漏；搜索禁用色/违禁词确认无残留。
